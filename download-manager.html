Access & setup

Setting up OminiTrain

Everything OminiTrain needs to run is at its official link. This page explains the setup steps and what to do if something does not work.

1. Open the app

Go to station-light.lovable.app. The journey planner is on the first screen.

2. Keep it on your home screen

Use your browser's Add to Home screen option so OminiTrain opens full screen next time.

3. Allow what you want to use

Notifications are needed for journey reminders, and location only if you ask OminiTrain to plan from where you are. Both are optional and asked for only when used.

If something does not work

  • Travel information needs a network connection; without one, OminiTrain says so instead of showing old times as current.
  • If a station shows no live information, the source is unavailable at that moment — scheduled times are labelled as scheduled.
  • Reminders only alert with sound or vibration if your device allows it for OminiTrain.
  • Still stuck? Write to cusmasobi888@gmail.com.
