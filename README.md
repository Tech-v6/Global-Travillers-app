# OminiTrain App — official companion website

**Your Journey, Everywhere.**

This repository publishes the companion website for **OminiTrain App**, an independent global travel-tech project.

- App: https://station-light.lovable.app
- Website: https://tech-v6.github.io/Global-Travillers-app/
- Contact: cusmasobi888@gmail.com

## What OminiTrain App does

OminiTrain supports people **before, during and after** their journeys:

- Journey planning between places, addresses and stations
- Travel information for stations, stops and routes, shown with its source
- Stations and destinations to explore
- One active journey the app follows from departure to arrival
- Journey reminders through the device's own notification system
- Travel assistance for connections and getting off at the right stop
- OminiJourney Memory for completed journeys, with your own title, notes and photos

Live information is labelled live only when genuinely confirmed live; timetable information is labelled as scheduled; when no reliable source is available, OminiTrain says the information is unavailable.

## Public media

The media section offers only files that genuinely exist in this repository. The official 512 × 512 PNG logo is downloadable at `assets/ominitrain-logo.png`. No separate promotional graphics or video files are currently stored here, so the website labels those categories unavailable rather than offering placeholder files.

The `app/` directory holds an earlier Android build configuration kept for history.

## Publishing

The site is served by GitHub Pages from the `main` branch. Edit the HTML files directly; there is no build step.
