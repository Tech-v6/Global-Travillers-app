## Detailed Installation Steps

### Step 1: Enable Installation from Unknown Sources

Android devices block installation from non-app-store sources by default.

**Android 11 and newer:**
- Open Settings
- Go to Apps → Special app access
- Select "Install unknown apps"
- Choose your browser/file manager
- Toggle "Allow from this source"

**Android 10 and older:**
- Open Settings
- Go to Security
- Enable "Unknown Sources"
- Confirm when prompted

### Step 2: Download the APK File

1. Visit the downloads page
2. Click the download button
3. Choose location to save (usually Downloads)
4. Wait for download to complete

### Step 3: Locate and Open the APK

1. Open File Manager app
2. Navigate to Downloads folder
3. Look for "GlobalTravellers_v1.0.0.apk"
4. Tap the file to start installation

### Step 4: Review Permissions

You'll see a permissions screen showing what the app needs:

- **Location**: Find nearby stations
- **Internet**: Download live transit data
- **Camera**: Optional QR code scanning

Tap "Install" to proceed.

### Step 5: Wait for Installation

- Installation usually takes 10-30 seconds
- You'll see a progress bar
- Once complete, tap "Open" or find the app in your app drawer

### Step 6: Launch and Explore

1. Open Global Travellers app
2. Grant requested permissions
3. Allow location access if prompted
4. Start exploring transit data!

## Troubleshooting

### "Installation blocked" error

**Solution:**
- Enable "Unknown Sources" in Security settings
- Use a different file manager or browser
- Check Android version is 7.0+

### "File corrupted" or "Package corrupt" error

**Solution:**
- Delete the downloaded APK
- Clear browser cache
- Download again from official website
- Ensure file downloaded completely

### "Not enough storage space" error

**Solution:**
- Delete unnecessary files or apps
- Clear app cache (Settings → Apps → Storage)
- Need at least 45 MB free space

### App won't launch after installation

**Solution:**
- Restart your device
- Check Android version (minimum 7.0)
- Reinstall the app
- Contact support if issue persists

### App crashes or freezes

**Solution:**
- Clear app data (Settings → Apps → Global Travellers → Clear Cache)
- Ensure you have latest version
- Update Android OS if available
- Restart phone

### No internet connection in app

**Solution:**
- Check WiFi or mobile data is enabled
- Disable VPN temporarily
- Check "Internet" permission is granted
- Restart app
