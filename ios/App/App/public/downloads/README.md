## Installation Instructions

### From APK Direct Download

1. **Enable Unknown Sources**
   - Go to Settings → Security
   - Toggle on "Unknown Sources"
   - This allows installation from files outside the Play Store

2. **Download the APK**
   - Click the download button on our website
   - File will save to your Downloads folder

3. **Install the App**
   - Open File Manager
   - Navigate to Downloads
   - Tap GlobalTravellers_v1.0.0.apk
   - Follow on-screen prompts

4. **Grant Permissions**
   - Location (for finding nearby stations)
   - Internet (for live data)
   - Camera (for QR code scanning)

5. **Launch the App**
   - Find Global Travellers in your app drawer
   - Tap to open and start exploring!
